# GitHub Pages 기반 구현 시퀀스 v0.2

## 현 상태
- Public GitHub 저장소에 업로드할 수 있는 정적 `index.html` 프로토타입 포함.
- 15개 지표 카탈로그와 5개 원천 그룹 정의 제공. 모든 지표는 공식 실데이터 미연결.
- GitHub Pages에 가상 데이터만 게시. 인증/DB/자동수집/공식 데이터 반영 없음.

> 시연 사이트가 공개라는 이유로 위 후속 데이터 및 인증 업무를 Public 저장소에 구현해도 된다는 뜻은 아닙니다. 내부자료·원본 통계·비밀값은 절대 커밋하지 않습니다.

## 첫 단계에 필요한 점검
1. 저장소 루트에 `index.html`, `.nojekyll`, `config/`, `docs/`가 있는가.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`로 지정됐는가.
3. Pages 주소로 열었을 때 9개 메뉴와 지표 15개가 나타나는가.
4. 시연 데이터 경고 문구가 상단 및 각 표/차트에 표시되는가.
5. 내부자료, 환경변수, API 키가 포함되지 않았는가.
