# 데이터 계보·해석과 다음 연동

## 현재 시연 데이터

원본 루트 demo_data.json / demo_monthly.csv를 data/로 내용 변경 없이 이동했다. JSON 월별 값 33행(2024·2025 각 12개월, 2026 9개월)은 합성 데이터이다. meta.asof는 시연 생성 기준일이며 실제 공표일·검증일이 아니다. 최신 시연 기준월은 관측 period의 최댓값으로 계산한다.

| 자료 | 지원하는 차원 | 표시 / 결측 원칙 |
|---|---|---|
| 전국 monthly | 연도·월 | 명, DEMO; 연 12개월이면 합계, 미완결 연도는 YTD |
| markets | 국가 표시명 | 기간 없는 모의 비중 %; 국가별 인원·성장률 아님 |
| regions | 7개 시군 표시명 | 기준 100 모의지수; 나머지 24개 시군은 결측 |
| resources | 시군·명칭·분류 | 자원 예시 스냅샷; 원본의 일반 포털 URL을 OTA 상품 URL로 사용하지 않음 |
| reports | 제목·기관·유형 문자열 | 기존 미검증 탐색 링크; 국가·발간일 추정 금지 |

현재 국가·시군 표시명은 합성 fixture 식별자이며 공식 국가/행정구역 코드 매핑을 뜻하지 않는다. 하위 시군 합산으로 경기도 전체 방문량을 만들지 않는다. 소비지수는 소비액이 아니며 카드소비 합계로 변환하지 않는다.

YoY = (이번 달 / 전년 같은 달 - 1) × 100. 동일 연월의 이전 연도 자료가 없거나 분모가 0·비유한 값이면 null이다. 누락 월을 인접 월로 대체하지 않는다. CSV에서 null은 공란이고 상태는 DEMO/미확보를 명시한다. 공식 지표 기준기간·공표일·최종 검증일은 연결 전 모두 — 이다.

## 다음 PR: 공식 방한관광 통계 수동 입력 어댑터부터

1. 담당자가 한국관광통계 공식 다운로드 파일과 이용조건을 확인한다. 미문서화 API·스크래핑을 가정하지 않는다.
2. 원본은 공개 Git 밖의 승인된 비공개 저장소에 보관한다. URL·SHA-256·공표일·기준월·국가분류·단위·vintage를 기록한다.
3. 파일 구조를 확인한 뒤 국가코드·기간·단위를 명시적으로 매핑한다. 연간 원표와 미완결 연도 YTD는 별도 정의로 유지한다.
4. KTO-01~05 관측/파생 산식을 구현하고, 0행·중복·결측·음수·국가코드 변경·0분모·정정 파일 fixture 테스트를 추가한다.
5. 원본 → 파싱 → 검증 → 차이/정정 이력 → 담당자 승인 → 공개 허용 snapshot 흐름을 분리한다. 검증 실패 시 기존 승인 snapshot을 유지한다.
6. 공개 가능 범위·인용조건·기관 승인 전 자동 수집/예약 실행/실데이터 게시는 하지 않는다. 지역 이동통신·카드소비는 별도 공급원·정의 검증을 거쳐 후속 PR로 분리한다.
